# Decisions

Decisions that apply to every epic in sprint-metrics, whatever its Goal. The crew's
refinement panel, the Product Owner's settle step and the split are shown every
Accepted entry here (mqucifer/crew#468).

Each is an ADR, in the form the crew uses for its own decisions: Date, Status,
Context, Decision, Consequences and Source. To change one, add an entry that
supersedes it and set the old one's Status to `Superseded by NNNN`; its body isn't
edited.

**Who writes it.** The Product Owner records a decision when its sources answer it,
or makes the call itself within the Goal and records it as its call. It asks the
Sponsor only when it can't tell which way the Goal points (crew ADRs 0016 and 0018).

**Seeded 2026-10-06** from decisions the Sponsor had already made, recorded on the
service Goal and in crew issues. The Sponsor reviews this first set once, because it
was found after the fact.
